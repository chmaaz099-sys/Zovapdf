## 📅 Daily Releases

### 🌟 Release v1.2 &bull; September 20, 2026 (Today)
- **✨ Dual Live Previews Everywhere**:
  - Added a dedicated **"Preview PDF"** button right inside the gallery toolbar.
  - Added an **Instant High-Res Image Lightbox Modal**: Click any image thumbnail or card inspect button to view the full uncompressed photo with rotate controls before converting.
  - Added dual sidebar action buttons: **"Preview & Convert to PDF"** and **"Instant Download (Skip Preview)"**.
- **✨ Document Scanner Filter (High-Contrast B&W)**:
  - Added an intelligent thresholding filter to turn phone snapshots of homework, paper notes, invoices, and receipts into crisp, clean, black-and-white scanned documents without messy background shadows.
- **✨ Grayscale & Vibrant Contrast Filters**:
  - Convert any colored image to monochrome grayscale or punchy vibrant contrast before compiling.
- **✨ Semi-Transparent Diagonal Watermarking**:
  - Added a dedicated text watermarking tool to stamp custom text (e.g., `CONFIDENTIAL`, `DRAFT`, `COPY`, or author name) diagonally across every page with customizable opacity (15%, 25%, 45%).
- **✨ One-Click Smart Gallery Sorting**:
  - Added `Sort A-Z` (alphabetical file sorting) and `Reverse Order` buttons in the workspace toolbar.
- **✨ In-App "What's New" Daily Release Modal**:
  - Direct access from the website header to view daily updates and roadmap.
- **✨ White Theme Default**:
  - Pristine, high-contrast light mode loaded by default with instant toggle to dark mode.
- **✨ Automated Daily Update Schedule Active**:
  - Background system cron job scheduled daily to inspect, build, test, and release new features.

### 🌟 Release v1.1 &bull; September 13, 2026
- **✨ Pure 1:1 Image Conversion (Zero Borders)**:
  - Eliminated unwanted white margins and letterboxing. PDF page sizes match the exact pixel dimensions of each individual image.
- **✨ Custom Themed PDF.js In-App Viewer**:
  - Replaced the browser's generic PDF viewer with a custom-themed canvas viewer with page navigation, zoom in/out, and fit-to-window controls.
- **✨ Rebranding**:
  - Officially renamed the web app to **Zenvixa PDF**.
- **✨ Custom Page Background Colors**:
  - Added White, Black, Dark Theme, and Custom hex color picker for fixed document layouts.

---

### 🌟 Release v1.0 &bull; Initial Launch
- Full client-side offline conversion via HTML5 Canvas and `jsPDF`.
- Drag-and-drop file upload & clipboard paste (`Ctrl + V`).
- Visual thumbnail gallery with drag-and-drop page reordering via `SortableJS`.
- Individual and bulk 90° image rotation.
- Standard document sizes (A4, Letter, A3, Legal).
- 100% Free, unlimited, and private (zero server uploads).
